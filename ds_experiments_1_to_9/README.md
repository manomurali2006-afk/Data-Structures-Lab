# Data Structures Using C — Experiments 1 to 9

Separate C programs based on the uploaded Data Structures Lab Manual.

| Experiment | Program |
|---|---|
| 1 | Vehicle Number Validation using 1D and 2D Arrays |
| 2 | Sudoku Board Validation using a Matrix |
| 3 | Student Record Management using Structures and Pointers |
| 4 | Stack using Arrays (PUSH and POP) |
| 5 | Queue using Arrays (ENQUEUE and DEQUEUE) |
| 6 | Singly Linked List |
| 7 | Doubly Linked List |
| 8 | Circular Linked List |
| 9 | Binary Search Tree (Inorder, Preorder, Postorder) |

## Compile and run

Open the required experiment folder in a terminal:

```bash
gcc main.c -o main
./main
```

On Windows, run `gcc main.c -o main.exe` and then `main.exe`.

Compile one experiment at a time because each folder contains its own `main()` function.
